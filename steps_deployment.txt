# DESARROLLO DEL MODELO
1. Entrenar el modelo y guardarlo
2. Testear el modelo para conocer las salidas esperadas

# DESPLIEGUE EN API (terminal 1)
3. Crear la API con "FastAPI" usando los métodos "GET" y "POST" necesarios --> app/main.py
4. Levantar API para poder usarla en una red interna
    4.1 uvicorn app.main:app --host 0.0.0.0 --port 8000 --> Para levantar la API
    4.2 http://192.168.1.XX:8000/docs --> para entrar a la API desde otro dispositivo conectando a la misma red
    4.3 Comprobar que efectivamente se devuelven los resultados esperados

# USO DE GRADIO COMO INTERFAZ (terminal 2)
5. Crear el script de backend por debajo de la interfaz de GRADIO --> gradio_app.py
6. Levantar la app de gradio --> python gradio_app.py
   Esto permite entrar a la plataforma y consumirla desde otros dispositivos conectados a la misma red compartiendo la IP
   http://192.168.1.XX:7860

# DOCKERIZACIÓN (terminal 3)
7. Descargar e instalar docker
8. Generar archivo dockerfile para dockerizar la solución
9. docker build --no-cache -t mlops-api-demo . --> Crear imagen docker para reproducibilidad futura
10. docker run -p 8000:8000 mlops-api-demo --> Ejecutar la imagen docker para poder hacer peticiones

# COMPARTIR ENLACE PÚBLICO CON ngrok (terminal 4)
11. Descargar e instalar ngrok
12. ngrok http 7860 --> via gradio --> https://lent-remedy-sulphate.ngrok-free.dev (hay que tener ejecutado el 6. y el 8.)
    ngrok http 8000 --> via API    --> https://lent-remedy-sulphate.ngrok-free.dev/docs  (hay que tener ejecutado el 8.)

# UTILIZAR RENDER para enlace PÚBLICO

13. Modificar el CMD del dockerfile --> CMD ["python", "-m", "uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
14. Descargar RENDER y crear un "New Web Service"
    14.1 Poner Language (runtime environment) --> Docker
    14.2 Poner region Oregon o Frankfurt
    14.2 Poner Instance Type --> Free (For hobby projects)
15. Subir el repo a github y conectarlo a Render
16. Se generará un endpoint en:
    https://mlops-api-demo.onrender.com/docs --> API
    https://mlops-api-demo.onrender.com/demo --> Si existe la función "demo_page()" para la interfaz web
